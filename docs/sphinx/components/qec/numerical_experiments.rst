Experiments
===========

``cudaq-qec`` provides utilities for running numerical error-correction experiments in batch, such as memory circuit experiments that measure how well a code and decoder preserve logical information under noise.

For the experiment APIs, see the :doc:`Python </api/qec/python_api>` and :doc:`C++ </api/qec/cpp_api>` API reference. For a runnable walkthrough, see the :doc:`Modeling Noise in QEC </examples_rst/qec/modeling_noise>` example.

:doc:`Conventions <conventions>` describes how errors, syndromes, and logical observables are laid out in the data these experiments return.
